# todo-бот для Telegram

Личный список задач с напоминаниями. Один Go-бинарник, SQLite, long polling, без cgo.

## Запуск

1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Запустите бота:

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...
go run .
```

Для сборки: `go build -o todo-bot .`

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | да | — | токен бота |
| `DB_PATH` | нет | `todo.db` | файл SQLite |
| `TZ` | нет | системный пояс | пояс для ввода и показа времени, например `Europe/Moscow` |

## Команды

- `/add <текст>` — добавить задачу, затем выбрать время кнопками.
- `/list` — активные задачи с кнопками «готово» и «удалить», по 10 на страницу.
- `/cancel` — отменить незавершённое добавление.
- `/help` — подсказка по форматам времени.

Бот работает только в личных чатах. У каждого пользователя свой список.

## Форматы времени

```
06.11 18:00
06.11.2026 18:00
6 ноября в 18:00
сегодня 18:00
завтра 9:30
послезавтра
в пятницу 18:00
через 30 минут
через 2 часа
через 3 дня
18:00
```

- Если время не указано — 09:00.
- Дата без года, которая уже прошла, переносится на следующий год.
- Явно прошедшее время (`вчера`, дата с годом) отклоняется.

Напоминание приходит один раз в срок. Пропущенные, пока бот был выключен, отправляются при старте.

## Ограничения

- Рассчитан на один запущенный экземпляр: так напоминания не отправляются дважды.
- Черновик добавления хранится в памяти: после перезапуска кнопки старого сообщения попросят начать заново.
- Выполненные задачи остаются в базе, но не показываются в `/list`.
- Тексты задач ограничены 200 символами.
